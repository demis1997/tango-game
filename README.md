# ∞ Tango

A sun & moon logic puzzle (Binairo / Takuzu style) with:

- **1000 journey levels** from easy 4×4 to very hard 10×10
- **Hints**, **undo**, and **timers** with personal-best tracking
- **Achievements** (banners, titles, profile borders)
- **Custom profile** icons & borders
- **Level randomizer**

## Rules

1. Equal suns and moons in every row and column  
2. No three identical symbols in a row  
3. `=` means adjacent cells are the same  
4. `×` means adjacent cells are different
